# Security Policy

## Supported Versions

The active research branch is `main`. Security and data-handling fixes should target `main` unless a release branch is introduced later.

## Reporting

Report security issues, leaked credentials, accidental inclusion of restricted data, or license-sensitive material privately to the repository owner.

Do not open a public issue that includes secrets, proprietary data, WRDS/CRSP/Compustat extracts, paid articles, or access tokens.

## Data Handling

The repository intentionally ignores raw data, interim data, processed data, generated reports, build artifacts, and private references. Commit only schemas, manifests, checksums, provenance metadata, code, and documentation that can be redistributed under the repository license.
