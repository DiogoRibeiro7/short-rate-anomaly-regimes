# Reports

Generated reports belong under `reports/generated`. They must be rebuilt from machine-readable artefacts and must not contain manually edited empirical numbers.

`reports/generated/replication_report.md` is the standalone baseline replication report. It is restricted to publication evidence, source definitions, baseline reconstruction, weak-factor diagnostics, and table-level audit records; it must not include regime, shock-decomposition, or post-publication extension results.
