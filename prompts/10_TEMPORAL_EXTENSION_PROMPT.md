# Temporal Extension Prompt

Complete Milestone 9.

## Data freeze

1. Set a precise latest common month and retrieval date.
2. Preserve the original 1972 to 2013 data as a locked baseline vintage.
3. Store revised historical data separately and quantify revisions.
4. Extend only compatible portfolio definitions and factors.
5. If an original portfolio set cannot be extended, report a reduced extension universe without rewriting the baseline.

## Out-of-original-sample tests

- apply December 2013 frozen betas and risk prices to post-2013 mean returns;
- separately estimate post-2013 betas and prices;
- use expanding and rolling estimates as secondary analyses;
- test whether anomaly spreads, beta ordering, risk prices, and pricing errors changed after publication;
- include publication-decay and post-publication anomaly checks without assuming causality.

## Outputs

Create tables and figures with a vertical December 2013 boundary. Report pre- and post-period observations and uncertainty. Never merge revised and unrevised vintages in one unlabeled series.
