# Release Prompt

Prepare a public research release.

1. Run all quality checks and clean-room reproduction.
2. Remove private PDFs, licensed data, credentials, and machine-specific paths.
3. Confirm public processed-data redistribution rights.
4. Include a data acquisition guide for sources that cannot be redistributed.
5. Produce checksums, environment manifest, SBOM, code archive, and release notes.
6. List exact, approximate, blocked, contradicted, and extension results separately.
7. Tag the release only after adversarial reviews have no critical findings.
