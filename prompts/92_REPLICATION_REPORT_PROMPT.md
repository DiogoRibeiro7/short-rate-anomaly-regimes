# Replication Report Prompt

Write the standalone replication report using only Milestones 0 through 8 artefacts.

Required structure

1. bibliographic target and versions;
2. accessible and inaccessible evidence;
3. exact source definitions;
4. factor reconstruction;
5. portfolio reconstruction;
6. estimator reconstruction;
7. table-level results by replication label;
8. weak-factor and influence diagnostics;
9. deviations from the article and their causes;
10. a bounded conclusion about what was and was not reproduced.

Do not include regime, shock decomposition, or post-2013 results. Do not turn inaccessible data into an accusation. Include the complete audit table as an appendix.
